# 本轮候选比较规则

候选：run_003的500/1000/1500/2000及修正后的run_004的500/1000。旧版为run_002/600。所有候选复算同一 full_3d reference-stance 口径，参考和物理模型相同。

先要求完整序列原有每阶段和末尾保持门槛通过、舞蹈关节RMSE<.13rad。几何近地点速度不得比旧 native 基线增加超过10%，问题段20–24及26–30秒中最差重力/角速度偏差不高于旧版最差值。

在合格候选中，以舞蹈阶段的四项动态指标各除以旧 native 基线再取均值，越低越好：重力方向RMS偏差、本体角速度RMS偏差、机身角加速度RMS、参考支撑点水平速度RMS。近地点运动作为独立诊断，不能宣称其等同接触滑移。该评分用于这一个动作的模型选择，并非通用平衡证书。

最后对选出的模型做3次真实DDS，仍需完整流程通过，并观察同样200Hz轨迹的改善是否复现；5ms/组合扰动继续检查完整流程。若复验失败，不能仅因native评分好就交付。

规则以旧基线为尺度，不按训练轮数决定选择。原始候选、基线指标和最终选择均保留，以便检验取舍。
